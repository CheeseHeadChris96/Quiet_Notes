Quiet Notes is a local desktop workspace for notes, photos, Gantt charts, and to-do lists.

## Changes in 0.22.0

- Reduced the top tab bar to 48 pixels.
- Pin and trash icons stay in the footer for notes, to-do pages, photo galleries, and Gantt charts. They are disabled when no item is selected.
- Pinned pages appear in Pinned. Trashed pages can be restored with their tasks or photos intact.
- Installed apps check GitHub for updates ten seconds after startup and every six hours. A new stable release prompts you to download the installer for your computer. More → Check for updates performs a check immediately. Later snoozes reminders for that version for 24 hours.
- Update checks do not automatically install or restart the app. Close Quiet Notes and run the downloaded installer. Versions before 0.22.0 need this update installed manually once to enable future prompts.

## Choose your installer

- **mac-arm64.dmg**: Macs with Apple silicon (M1 or newer).
- **mac-x64.dmg**: Macs with an Intel processor.
- **windows-x64-Setup.exe**: Windows 11 PCs with Intel or AMD processors.

Mac builds require macOS 12 or newer. Open the DMG and drag Quiet Notes into Applications. On Windows, run Setup and follow the installation wizard. Node.js and a web server are not required.

These initial builds are **not signed by a verified publisher or notarized by Apple**. macOS Gatekeeper and Windows SmartScreen may display a warning or block them. Managed devices may require IT approval. Only proceed if you trust this repository and its release assets. Production signing can be added when publisher certificates are available.

Notes stay on your device. To transfer notes from the browser prototype or another computer, export a backup from More and import it into the installed app. Keep a backup before upgrading. The app automatically checks for new releases and offers the matching installer. Installing and restarting remain manual steps with these unsigned builds.

SHA256SUMS.txt contains checksums for the installers. The source archives generated by GitHub are for developers, not installers.
